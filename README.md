# .github

Organisation-wide files for [ayeo-io](https://github.com/ayeo-io). GitHub uses these as defaults for any ayeo repo that doesn't have its own.

| Path | What it does |
|---|---|
| `profile/README.md` | The profile on the organisation page |
| `CONTRIBUTING.md` | How to contribute to an ayeo project |
| `AI_POLICY.md` | How we handle AI-assisted contributions |
| `CODE_OF_CONDUCT.md` | Expected behaviour in our spaces |
| `SECURITY.md` | How to report a vulnerability |
| `SUPPORT.md` | Where to get help |
| `ISSUE_TEMPLATE/` | Default issue forms (bug, feature, spec proposal) |
| `PULL_REQUEST_TEMPLATE.md` | Default PR template |
| `templates/CLAUDE.md` | Starter agent instructions for new ayeo repos |
| `assets/` | Logos used by the profile, plus the social preview image |

A repo can override any of these by adding its own copy. Note that the templates in `templates/` aren't applied automatically. Copy them in when you set up a new repo.

Brand assets are generated, so don't edit the SVGs by hand. Regenerate them from the source and copy them in.

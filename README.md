# .github

Organisation-wide files for [ayeo-io](https://github.com/ayeo-io).

- `profile/README.md` - the profile shown on the organisation page
- `assets/` - logos used by the profile, plus the social preview image (`assets/web/og-image.png`)

Brand assets are generated, so don't edit the SVGs by hand. Regenerate them from the source and copy them in.

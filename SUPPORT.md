# Getting help

- **Questions and ideas:** start a discussion in the relevant repo's Discussions tab.
- **Bugs:** open an issue using the *Bug report* form.
- **New behaviour:** open a *Feature request*, or a *Spec proposal* if you've already thought through how it should work.
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them publicly.

ayeo is a small team, so we can't promise quick replies, but we do read everything.
